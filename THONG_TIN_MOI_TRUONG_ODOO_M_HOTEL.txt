PHẦN 5: BỘ LỆNH QUẢN TRỊ & VẬN HÀNH HỆ THỐNG (CLI CHEAT SHEET)
----------------------------------------------------------------------------------------

Mở PowerShell tại thư mục `C:\Projects\M-Hotel` (hoặc mở Terminal trong IDE):

1. Khởi động toàn bộ hệ thống (Background / Daemon):
   docker compose up -d

2. Xem trạng thái các container đang chạy:
   docker ps

3. Xem nhật ký hoạt động (Logs) của Odoo:
   docker compose logs -f web

4. Xem nhật ký hoạt động của PostgreSQL:
   docker compose logs -f db

5. Khởi động lại container Odoo (sau khi chỉnh sửa code Python):
   docker restart m-hotel-web-1

6. Nâng cấp module m_hotel khi cập nhật file XML/Views/Data:
   docker exec -i m-hotel-web-1 odoo --db_host=db --db_user=odoo --db_password=dev_only_change_me -d mhotel_dev -u m_hotel --stop-after-init

7. Chạy bộ kiểm thử tự động (12 Test Cases):
   docker exec -i m-hotel-web-1 odoo --db_host=db --db_user=odoo --db_password=dev_only_change_me -d mhotel_dev --test-enable --test-tags=/m_hotel --stop-after-init

8. Dừng hệ thống khi không sử dụng:
   docker compose stop

9. Dừng và hủy containers (Dữ liệu database trong volume vẫn được giữ nguyên an toàn):
   docker compose down

----------------------------------------------------------------------------------------

1. Sao lưu dữ liệu Database ra file SQL (Backup):
   docker exec -t m-hotel-db-1 pg_dump -U odoo mhotel_dev > backup_mhotel_dev.sql

2. Sao lưu toàn bộ Database kèm Filestore qua giao diện Web Odoo:
   - Truy cập: http://localhost:8069/web/database/manager
   - Tìm database `mhotel_dev` -> Bấm nút `Backup`
   - Nhập Master Password: `mhotel_dev_master_change_me`
   - Chọn định dạng: `zip (includes filestore)`
   - Tải file backup nén về máy lưu trữ an toàn.

3. Phục hồi dữ liệu từ file sao lưu (Restore):
   - Truy cập: http://localhost:8069/web/database/manager -> Bấm `Restore Database`
   - Chọn file zip vừa tải về và nhập tên DB mới.

PHẦN 8: XỬ LÝ SỰ CỐ THƯỜNG GẶP (TROUBLESHOOTING FAQ)
----------------------------------------------------------------------------------------

1. Lỗi "docker : The term 'docker' is not recognized":
   - Nguyên nhân: Biến môi trường PATH của PowerShell chưa nhận thư mục Docker Desktop.
   - Cách khắc phục: Chạy lệnh sau trong PowerShell trước khi gõ lệnh docker:
     $env:Path += ";C:\Program Files\Docker\Docker\resources\bin"

2. Lỗi Port 8069 bị xung đột (Address already in use):
   - Nguyên nhân: Có tiến trình Odoo hoặc service khác đang chiếm port 8069.
   - Cách khắc phục: Kiểm tra tiến trình bằng lệnh:
     Get-NetTCPConnection -LocalPort 8069
     Hoặc khởi động lại container: docker restart m-hotel-web-1

3. Giao diện Odoo báo "Session Expired" hoặc không hiển thị menu M-Hotel:
   - Cách khắc phục: Bật chế độ Debug Mode bằng cách thêm `?debug=1` vào URL:
     http://localhost:8069/web?debug=1
   - Vào menu `Apps` -> Bấm `Update Apps List` -> Tìm kiếm `M-Hotel` và bấm `Upgrade`.
