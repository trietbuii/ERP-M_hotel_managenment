PHẦN 1: TỔNG QUAN KIẾN TRÚC MÔI TRƯỜNG CÔNG NGHỆ ODOO 19
----------------------------------------------------------------------------------------
Hệ thống ERP M-Hotel đã được chuyển đổi và nâng cấp hoàn chỉnh lên nền tảng Odoo 19 Community,
triển khai theo kiến trúc Container hóa (Docker) độc lập và chuẩn mực:

1. Hệ điều hành máy trạm (Host OS):
   - Linux (Ubuntu 64-bit AMD64) / Windows 11 WSL2
   - Quản lý Container: Docker Engine & Docker Compose v2

2. Nền tảng Container hóa:
   - Docker Service: Docker Desktop / Docker CE
   - Docker Compose: v2.x (điều phối cụm web và db)
   - Mạng nội bộ Docker: Driver bridge (tên mạng `m-hotel_docker_default`)

3. Ứng dụng lõi ERP:
   - Phiên bản: Odoo 19.0 Community Edition (Docker Image: `odoo:19`, Build: 19.0-20260926)
   - Môi trường thực thi: Python 3.12.3 / Werkzeug 3.0.1
   - Xuất báo cáo PDF: Wkhtmltopdf 0.12.5 (tích hợp sẵn trong container)
   - Kiến trúc giao diện: 100% Giao diện chuẩn Native Odoo Backend (Form, List, Kanban, Search, Pivot, Graph, Chatter)

4. Hệ quản trị cơ sở dữ liệu (DBMS):
   - PostgreSQL: Phiên bản 15 (Docker Image: `postgres:15`)
   - Tên cơ sở dữ liệu: `mhotel_dev`
   - Quản lý lưu trữ: Persistent Docker Volumes (`odoo-data` và `db-data`)

5. Kiến trúc Module hóa (Modular Architecture):
   Hệ thống gồm 6 module nghiệp vụ chuyên biệt + 1 meta-module cài đặt tổng:
   (1) `m_hotel_base`: Nền tảng danh mục, chi nhánh khách sạn, hạng phòng, phòng, giá mùa & phân quyền 5 nhóm người dùng.
   (2) `m_hotel_booking`: Đặt phòng (theo giờ / theo đêm), Check-in, Check-out, Folio dịch vụ & Hóa đơn tự động (Account).
   (3) `m_hotel_housekeeping`: Quản lý buồng phòng, nhiệm vụ dọn dẹp, xử lý sự cố & khóa phòng khẩn cấp.
   (4) `m_hotel_inventory`: Định mức vật tư phòng (Amenities/Minibar), tự động xuất kho tiêu hao qua module Stock.
   (5) `m_hotel_asset`: Trang thiết bị trong phòng, liên kết bảo trì kỹ thuật qua module Maintenance.
   (6) `m_hotel_report`: Báo cáo công suất buồng phòng (Occupancy Rate) & phân tích doanh thu.
   (7) `m_hotel`: Meta-package umbrella cài đặt 1 chạm toàn bộ hệ thống.

PHẦN 3: ĐẶC TẢ TƯƠNG THÍCH CHUẨN ODOO 19 (MIGRATION HIGHLIGHTS)
----------------------------------------------------------------------------------------

Khi chuyển đổi từ Odoo 17 sang Odoo 19 Community, mã nguồn đã được cập nhật đáp ứng 100%
chuẩn kiến trúc kỹ thuật mới của Odoo 19:

1. Chuyển đổi định dạng View danh sách:
   - Trong Odoo 19, thẻ `<tree>` đã bị loại bỏ hoàn toàn khỏi RelaxNG schema.
   - Toàn bộ các file XML view đã chuyển sang thẻ `<list>` và `</list>`.
   - Các thuộc tính `view_mode` trong các action `ir.actions.act_window` được khai báo dạng `kanban,list,form`.

2. Cập nhật cơ chế ràng buộc cơ sở dữ liệu (Database Constraints):
   - Odoo 19 loại bỏ thuộc tính `_sql_constraints` kiểu tuple cũ.
   - Chuyển đổi sang `models.Constraint('unique(...)', 'Thông báo lỗi')` chuẩn Odoo 19 ORM.
   - Áp dụng trên `hotel.room.type` (mã hạng phòng duy nhất theo cơ sở) và `hotel.room` (số phòng duy nhất theo cơ sở).

3. Chuẩn hóa thẻ tìm kiếm `<search>` & `<group>`:
   - Loại bỏ các thuộc tính không hợp lệ trong RelaxNG Odoo 19: `expand="0"` và `string="Nhóm theo"` trên thẻ `<group>` bên trong `<search>`.
   - Giữ nguyên nhóm bộ lọc `context="{'group_by': ...}"` hoạt động mượt mà trên thanh tìm kiếm tiêu chuẩn.

4. Cập nhật nhóm quyền bảo mật `res.groups`:
   - Phù hợp với thay đổi lược đồ quyền hạn người dùng Odoo 19 (chuyển sang `privilege_id` thay vì `category_id`).

5. Chuẩn giao diện:
   - 100% Native Backend Views của Odoo 19, hỗ trợ đầy đủ Desktop và Mobile Responsive.
   - Tuyệt đối không can thiệp các đoạn mã HTML/JS ngoài luồng hay iframe bên thứ ba, bảo đảm tính ổn định lâu dài.

PHẦN 5: BỘ LỆNH QUẢN TRỊ & VẬN HÀNH HỆ THỐNG TRÊN ODOO 19 (CLI CHEAT SHEET)
----------------------------------------------------------------------------------------

Mở Terminal tại thư mục `M-Hotel_Docker`:

1. Khởi động toàn bộ cụm dịch vụ Odoo 19 (Daemon):
   docker compose up -d

2. Xem danh sách containers đang chạy:
   docker compose ps

3. Xem nhật ký hoạt động (Logs) của Odoo 19:
   docker compose logs -f web

4. Khởi động lại dịch vụ Web Odoo:
   docker compose restart web

5. Nâng cấp (Upgrade) toàn bộ các module M-Hotel sau khi chỉnh sửa XML/Python:
   docker exec -i m-hotel-web odoo -c /etc/odoo/odoo.conf -d mhotel_dev -u m_hotel --stop-after-init

6. Chạy bộ kiểm thử tự động (Unit Tests) trên Odoo 19:
   docker exec -i m-hotel-web odoo -c /etc/odoo/odoo.conf -d mhotel_dev --http-port=8070 --test-tags /m_hotel_booking,/m_hotel_housekeeping,/m_hotel_inventory --stop-after-init

7. Sao lưu dữ liệu Database ra file SQL:
   docker exec -i m-hotel-db pg_dump -U odoo mhotel_dev > backup_mhotel_dev_v19.sql

8. Dừng hệ thống khi không sử dụng:
   docker compose stop
